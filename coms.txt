6. DOCKER-BEFEHLE (häufig gebraucht)
------------------------------------------------------------

# Logs eines Services anschauen
docker compose logs -f backend
docker compose logs -f celery_worker
docker compose logs -f frontend

# Einzelnen Service neu starten
docker compose restart backend

# Direkt in die Datenbank
docker compose exec postgres psql -U agrolens -d agrolens_dev

# Alles stoppen und Volumes löschen (kompletter Reset)
docker compose down -v


------------------------------------------------------------
7. FALLS DOCKER BUILD FEHLER AUFTRETEN
------------------------------------------------------------

Fehler: "No module named pkg_resources"
→ Dockerfile muss haben:
   RUN pip install "setuptools<81" pip --upgrade && \
       pip install --prefix=/install -r requirements.txt

Fehler: "npm ci" failing
→ Dockerfile frontend deps stage:
   if [ -f package-lock.json ]; then npm ci; else npm install; fi

Fehler: rasterio baut nicht
→ Builder stage braucht: libgdal-dev libgeos-dev libproj-dev gdal-bin
